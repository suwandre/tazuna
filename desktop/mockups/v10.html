Design review 13 · polish proposals

Each row shows the app as it is today next to a proposal. Terminal rows are drawn cell by cell in tazuna's own terminal palette at 72 columns. Desktop rows use DESIGN.md's tokens. Use the panel at the bottom right to switch theme, accent and motion.

Terminal

T1A working indicator people recognise

Today the run shows a braille spinner with "Working 2 s" at the right edge of the status line. Proposed: the live end of the transcript carries the 手 mark and a shimmer over "Working", stepped one cell per frame on the same clock as the spinner, with elapsed time and live output tokens. Claude Code has ✻ and Codex a shimmer; this would be tazuna's.

Proposed

T2Your messages stand out when you scroll

Today your message is only italic text and reads like a note from the model. Proposed: an accent ▎ gutter, a faint band the width of the column, upright text. The same in zen and cockpit (cockpit's "│ you" label goes).

Today
Proposed

T3What changed, without Ctrl-O

Today a finished run folds everything into "ran 4 tools …", and the edits stay hidden until Ctrl-O. Proposed: one change line under each run (files, +/−, a hint). Expanded diffs get tinted bands, a line-number gutter and word-level marks. No syntax highlighting: that would mean a grammar engine in a 6 MB binary, against the small-footprint goal.

Today (Ctrl-O open)
Proposed (folded, then open)

T4The permission mode as a coloured pill, auto included

Today the status line shows [ask] or [full], and auto shows nothing, so you can't tell auto from a missing label. Proposed: a pill with a dot, warn-coloured for full. The question bar names the rule it hit and wraps instead of cutting off "· al".

Proposed

T5Long answers: air above headings, simple maths as text

Today headings sit straight under the paragraph above, and maths prints raw. Proposed: a blank line above each heading, headings in ink with an accent mark, and simple TeX without its $$ fences: Greek letters and symbols as Unicode, in italics.

Proposed

T6Leaving: a recap and the way back

Today the last line is a session file path. Proposed: one recap line (turns, files changed, cost, time) and the command that resumes it.

T7The terminal's own background

Today tazuna paints its own warm black over every cell, so a terminal with its own colour and padding shows a frame around it, shown here in a Catppuccin-like terminal. Proposed: tazuna reads the terminal's background (OSC 11), picks light or dark from it, and a "terminal" theme leaves the background alone, keeping the surface colour only for panels and bands.

D4The mode pill says how much freedom it gives

Today every mode looks the same, a grey shield. Proposed: full is warn-tinted, plan is accent-tinted, and the rest stay neutral. You can tell at a glance that a conversation runs with no questions.

D5A destructive question reads as one

Today the card says "tazuna asks to use bash", and Allow is the filled button. Proposed: the card names the rule auto hit, Allow and Decline carry equal weight, and there is no Always for a destructive command. This one is already in the bug-fix round; it's here so the set reads as one.
