B · Stats in the work panel

A new section at the top of the work panel (it already holds Changes and Your messages). It covers this turn or the whole conversation. Tiles show the headline numbers, each with a line of context. Every metric that varies per call gets a sparkline: one line in the live colour, a hover crosshair with the call's value, and no axes to read. While a reply runs, the numbers count up smoothly with each call and the newest point grows in. Reduced motion jumps instead.

What each number is

  • In: tokens sent, with the share read from the cache (the hit rate). Hovering the bar splits fresh and cached.
  • Out: tokens written, with average speed (tokens per second while writing).
  • Cost: what was paid, or on a plan, its value at API prices with "not billed".
  • Time to first token: the last call's, with the median; the sparkline shows each call.
  • Speed: tokens per second while writing, per call, and end to end for the turn.
  • Cache hit rate: per call, so you see the cache warm up after the first call.
  • Context: how full the model's window is, from the last call.

The terminal's cockpit has these numbers already. This brings them to the window, in the same words.
