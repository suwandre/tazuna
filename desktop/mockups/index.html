The same window in each (mockups, docs/DESKTOP.md). Each page has a light/dark switch at the bottom right.

A · Warm PaperCursor and Anthropic family: cream canvas, warm ink, one indigo accent, hairlines, a serif for prose.B · Midnight InstrumentLinear and Raycast family: near-black graded surfaces, dense, small mono labels, one violet accent.C · Quiet TerminalCarries the TUI over: mono-led, monochrome with one status colour, glyph markers, grid alignment.D · Editorial ContrastVercel and Swiss family: pure black and white, strong type scale, hard edges, no accent but ink, generous whitespace.E · Nordic CalmSoft cool greys and a sage accent, native-feeling rounded controls, airy spacing; calm for long chats.
