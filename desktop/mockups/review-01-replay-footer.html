What both directions fix

  • Replace Message tazuna… / say something… with an unmistakable replay surface.
  • Keep q quit and the paused state visible at 80 columns, without truncating e expand.
  • Label the first frame as an offline recording, never a live connection.
  • Retain the hand mark, existing terminal palette and both layouts. No new keys or help screen.

Try the states, not a live session

The toolbar changes both frames together. Focus either preview and try Space, e, ← / → or r. Use the toolbar for layout and scroll normally in the browser.

Browser Tab keeps normal focus navigation; the proposed Tab layout hint describes the terminal's existing key. Quit is a label only here. Text is selectable; no network, agent, storage or terminal process is used.

Column counts are preserved. A browser narrower than the selected terminal pair scrolls inside each preview; simulated rows are never truncated.

Start with A.

It fixes the misleading replay surface with the least height and keeps the transcript first. Choose B if keeping every playback hint beside the state matters more than that extra row. Neither direction is implemented.
