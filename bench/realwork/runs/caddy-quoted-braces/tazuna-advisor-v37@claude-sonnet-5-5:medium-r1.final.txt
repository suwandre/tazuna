Quoted `{` and `}` no longer count as block delimiters, so the Caddyfile from the issue now adapts, with `"body": "{"` in the JSON. The `caddyconfig/...` tests pass with `-race -short`. The `caddytest/integration` package passes without `-race`, and the new adapt test passes. I didn't run `golangci-lint`.

The lexer already recorded whether a token was quoted, but most brace checks only compared the token text. I added two small unexported helpers in `lexer.go`, `isOpenBrace()` and `isCloseBrace()`, which are true only for unquoted braces. I switched the brace checks over to them in `parse.go` and `dispenser.go`. That covers the block-nesting logic, `NextArg`, `NextBlock`, `ArgErr`, snippet/import token handling, `blockTokens`, and the open/close assertions. In the site-address loop I just added `!p.Token().Quoted()` to the existing `{` check.

I also ran `caddy fmt` on a file with `respond "}"` and a backtick `{`. It left both untouched, so the formatter needed no change.
