**Behaviour changes you should know about:**
- **Non-literal results:** when the experimental flag is on, a parenthesised literal such as `foo offset (5m)` or `foo[(5s)]` no longer gives a plain offset or range at parse time. It's stored as an expression and turned into a number at query time, the same as `(5m + 1m)` already is.
- **Negated ranges:** `foo[-(5)]` used to fail at parse time; now it fails when the query runs, as `foo[-(5s + 1s)]` already did. Parse-time errors are kept for `foo[(0)]` and for division or modulo by `(0)`.
- **Flag off:** `foo offset +(5)` and `foo offset -(5)` still parse into a plain offset and print as `5s` and `-5s`, so the output still parses without the flag.
