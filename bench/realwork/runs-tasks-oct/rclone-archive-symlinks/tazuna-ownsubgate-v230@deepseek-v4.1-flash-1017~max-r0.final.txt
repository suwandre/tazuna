## What changed

`backend/archive/zip/zip.go` (`readZip`):

- Removed the unconditional `dt.Find(remote)` call (which is documented as O(N) and made reading a zip O(N²) in files per directory).
- Clash handling now only runs when `f.links` is set **and** the name ends in `fs.LinkSuffix` — the only case where a symlink and a regular member can collide. Otherwise the entry is simply `dt.Add`ed, exactly as before the symlink change.
- For that narrow case, a `map[string]int` (`added`) records the index of each link-suffixed object added so far, so a later regular member with the same name replaces the symlink in place in O(1) rather than searching the directory. The map is only allocated when `--links` is on.
