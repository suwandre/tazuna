Implemented symlink support in the archive backends at `/Users/suwandre/bench-repos/rclone`.

### Changes

- **ZIP backend** (`backend/archive/zip/zip.go`)
  - Detects `os.ModeSymlink` entries.
  - Skips them by default and logs a notice mentioning `-l/--links`.
  - With `--links`, exposes them as `<name>.rclonelink`, preserving target content and existing range/seek behavior.
  - Regular members ending in `.rclonelink` remain regular files.

- **Squashfs backend** (`backend/archive/squashfs/squashfs.go`)
  - Reads symlink targets from squashfs stat metadata.
  - Applies the same skip/notice and `--links` naming behavior.
  - Makes `List` and `NewObject` agree on symlink names.
  - Serves link targets from memory while honoring range and seek options.

- **Tests**
  - Added ZIP symlink listing/lookup/read coverage.
  - Added squashfs symlink end-to-end coverage.
  - Added hostile ZIP symlink escape coverage.

### Verification
