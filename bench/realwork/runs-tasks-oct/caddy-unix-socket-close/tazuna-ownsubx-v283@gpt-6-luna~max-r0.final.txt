Implemented Unix socket cleanup and reload handling.

### Changes
- Closed temporary duplicated socket FDs created during listener reuse.
- Removed socket paths using the Unix address rather than `os.File.Name()`.
- Added synchronized reference counting so the socket and file are removed only after the final holder closes.
- Made listener and packet-connection closes idempotent; repeated closes return `net.ErrClosed`.
- Serialized close/relisten operations to prevent an old listener from removing a newly-created socket.
- Avoided unlinking Linux abstract sockets.
- Added tests for stream sockets, `unixgram`, close/relisten races, reference counting, duplicate closes, and abstract sockets.

- `go build ./...`

- Cross-compiled tests for Linux, FreeBSD, Windows, and Solaris.
