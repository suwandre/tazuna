Implemented Unix socket lifecycle cleanup and reload safety.

### Changes
- Close duplicated socket FDs returned by `File()` to prevent GC-dependent listeners.
- Unlink the actual Unix socket address rather than the duplicated file descriptor’s name.
- Add reference-counted, idempotent close handling for Unix listeners and packet connections.
- Serialize close/relisten operations and preserve replacement sockets during reload races.
- Avoid unlinking Linux abstract sockets (`@...`) or filesystem paths with the same name.
- Prevent replacement sockets using another Unix network type from being unlinked.
- Return `net.ErrClosed` on repeated closes for reusable listener wrappers.
- Added regression tests covering stream/datagram sockets, reference counting, double close, relisten races, immediate unlinking, and abstract sockets.
