Implemented response-aware `lb_retry_match` handling.

### Changes
- CEL expressions now identify whether they reference response-dependent placeholders:
  - status code/text
  - response headers
  - upstream latency placeholders
  - dynamically resolved placeholder names are treated conservatively as response-dependent
- Request-only expressions, including upstream host and escaped/string-literal placeholder text, no longer cause successful responses to retry.
- Added regression coverage for request-only POST expressions and placeholder classification.
