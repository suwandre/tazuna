### Describe the Bug

When using `<ClientRouter />` with `html { scroll-behavior: smooth; }`, navigating back or forward animates the scroll restoration.

Without `<ClientRouter />`, the browser restores the scroll position instantly with the same CSS.

The router calls `scrollTo()` without specifying `behavior: 'instant'`, so it follows the CSS smooth scrolling setting.

https://github.com/user-attachments/assets/a8e49242-a979-48d7-8fad-af1845209364

### What's the expected result?

Back/forward navigation should restore the saved scroll position instantly, matching the browser's default behavior. Anchor navigation should still respect smooth scrolling.
