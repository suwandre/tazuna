_No response_

### Describe the Bug

When running `astro dev`, `[data-astro-transition-scope="..."] { view-transition-name: ... }` styles are missing when the component with the `transition:name` directive is nested inside another component, that itself has no style, script or css import of its own. In the linked stackblitz this can be seen by removing the `<Dot />` component from the index.astro file. In that case Dot is only included via the Menu component which causes the styles not to be emitted. Running the repo as is (Dot imported in index.astro) yields the appropriate style `[data-astro-transition-scope="..."] { view-transition-name: the-dot; }...` in the output.
NOTE: I can't get stackblitz to actually run this repro, but it works when checking it out locally

### What's the expected result?

`data-astro-transition-scope` styles should always be emitted in dev mode when an element with `transition:name` is present
