All done. Summary of changes:

**Core helper** — `common/hreflect/numbers.go` (new):
- `CompareNumbers(a, b reflect.Value) (int, bool)` compares signed ints, unsigned ints and floats exactly, without going through `float64`. Mixed float/integer comparisons use `math.Trunc` + range checks, so values like `int64(9007199254740993)` vs `float64(9007199254740992)` and `uint64` max vs `-1` are exact. Returns `ok == false` for NaN (unordered).

**`tpl/compare`**:
- `Eq` now compares two numbers via `CompareNumbers` (so `ne` follows), keeping the existing `Eqer` precedence and `DeepEqual` path for non-numbers.
- `compareGetWithCollator` short-circuits when both operands are numeric and maps the exact result to the existing normalized `(left, right)` pair (`compareTwoNumbers` replaces `compareTwoUints`); NaN maps to `(NaN, 0)` so all ordered comparisons stay false. Removed the lossy uint/float conversion branches that are now unreachable.

**`tpl/collections/where.go`**:
- `checkCondition` now routes any numeric/numeric pair through `CompareNumbers` for `eq`/`ne`/`gt`/`ge`/`lt`/`le`, matching the template function rules (including NaN semantics), while leaving `in`/`intersect`/`like` behavior untouched.
